Ejercicio 3.4

Indique si cada uno de los siguientes enunciados es verdadero o falso. Si es falso, explique por qué.

a) Los navegadores que despliegan el tipo input color como campo de texto requieren que el usuario introduzca el nombre de un color. Falso. El usuario puede introducir un valor de color.

b) Cuando un usuario introduce datos en un formulario y luego lo envía (por lo general, al hacer clic en el botón Enviar), el navegador verifica de inmediato que los datos sean correctos. Verdadero.

c) HTML5 puede validar si la dirección de correo electrónico introducida por el usuario existe en realidad. Falso. HTML5 sólo puede validar que la dirección tenga un formato válido, pero no puede comprobar si la dirección existe realmente.

d) Puede agregar required a cualquiera de los tipos input. Falso. El atributo required no se puede utilizar con todos los tipos input.

e) Puede habilitar autocomplete sólo para ciertos elementos input. Verdadero.

f) El elemento time nos permite identificar una fecha, hora o ambas. Verdadero.

g) El elemento caption proporciona una leyenda para la imagen en un elemento figure. Falso. El elemento figcaption proporciona una leyenda para la imagen en un elemento figure.

h) El elemento details muestra una flecha que apunta a la derecha enseguida de un resumen o leyenda cuando el documento se despliega en un navegador. Al hacer clic en la flecha, ésta apunta hacia abajo y revela el contenido del elemento summary. verdadero.

i) El elemento footer describe el contenido que por lo general aparece en la parte inferior del contenido o del elemento section. Verdadero.

j) El elemento highlight nos permite resaltar texto. Falso. El elemento mark nos permite resaltar texto.
